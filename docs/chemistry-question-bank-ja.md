# CampusSync 化学問題バンク

更新日: 2026-11-23

初期リリースは**211問**。理論化学64問、無機化学48問、有機化学51問、高分子化学48問。選択式195問と理論化学の数値入力16問を含む。

問題文・選択肢・正答・解説はCampusSync独自作成で、外部サイトの問題を無断転載していない。
