# CampusSync 化学問題バンク

更新日: 2026-11-23

現行バンクは**1,500問**。理論化学400問、無機化学400問、有機化学400問、高分子化学300問。選択式1,124問と数値入力376問を収録する。

問題文・選択肢・正答・解説はCampusSync独自作成で、外部サイトの問題文や図版を無断転載していない。公開教材は単元構成・学習範囲・出題形式の参考としている。

## 収録数

| 分野 | 科目コード | 問題数 |
|---|---|---:|
| 理論化学 | chem_theory | 400 |
| 無機化学 | chem_inorganic | 400 |
| 有機化学 | chem_organic | 400 |
| 高分子化学 | chem_polymer | 300 |
| **合計** | | **1,500** |

設問には基礎知識、性質・反応・実験観察、化学式・生成物の判定、物質量・濃度・pH・滴定・気体・熱量・電気量・高分子の重合度などの計算を含む。知識事項の確認では、問い方や適用場面を変えた問題も収録しているため、**1,500問は1,500個の完全に独立した概念を意味するものではない**。数値計算は与える条件や値を変えた問題を含む。
