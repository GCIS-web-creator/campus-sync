# 地上視点の現状アーキテクチャ

- 調査日: 2026-11-28 / 対象: `0a66b36`(2026-11-27に本番デプロイ。GitHub Actionsのデプロイ手順成功を確認)
- 測定はヘッドレスChromium+ソフトウェアGPU(SwiftShader)。**fps・実機性能は未測定**。

## 1. 構造

```
PlanetCivilization (stage, planet_asset_id を保持)
└ Planet3DPanel  viewMode: orbit | ground | voyage | free-flight
   └ ground → CityGroundView {planetId, planetName, atmosphereColor, stage, onBack}
        ├ lib/planet-city.ts          buildCityLayout(planetNumber, stage)  建物配置(純関数)
        ├ planet-world/city-shaders.ts ファサード・空・路面・ホログラム・光芒
        └ planet-world/city-props.ts   道路上と屋上の物体・看板・緑化・空中交通
```

- 地上視点中は惑星視点のレンダラーを破棄し、WebGLコンテキストは1つ。
- `planetId` / `atmosphereColor` / `stage` が変わるとシーン全体を作り直す。昼夜切替は作り直さない。
- `VerdiaGroundView.tsx`(975行、地形・住宅・ヴェルディア素材アトラス)は**どこからもimportされていない**。素材の展開とテストはビルドで継続している。以前の49惑星用地形ビュー(`PlanetGroundView` / `planet-ground`)と着陸5地点は削除済み(PR #71)。

## 2. カメラ・操作

| 項目 | 値 |
|---|---|
| 位置 | 固定 (x −3.5, y 1.65, z 20)。移動不可 |
| 画角 | 70°(ホイール/ピンチで40〜82°)。縦長画面は+14°(上限96°) |
| 仰角 | 初期22°(縦長30°)、約−7°〜83° |
| 方位 | ドラッグで360° |
| near / far | 0.2 / 9,000 |
| 入力 | pointer・wheelのみ。キーボード操作なし |

## 3. 地面・道路

- 地形は無し。3,200 m四方の平面1枚に three.js `Reflector` とカスタムシェーダー。
- 車道は |x| < 約7.5 m。夜: 濡れたアスファルト、水たまり、反射ぼかし、車線、縁の発光線。昼: 舗装タイル、芝帯。
- 反射テクスチャは表示サイズ×pixelRatio×0.6(各辺≤1,024)。**生成時に固定で、リサイズ・回転に追従しない**。
- 街路の半幅は13 m。交差点・道路網は無い(直線1本)。

## 4. 建物生成アルゴリズム

シード `planetNumber × 104729 + 17` の線形合同法。Stage 0・全50惑星で3,114〜3,208棟(惑星1: frontage 93 / midtown 2,938 / tower 81 / landmark 2)。

1. 通り沿いの壁面(両側、z 130→−500、高さ14〜58 m)と2列目(|x| 46〜56、48〜125 m)
2. 通り正面奥(z≈−525)の低層列
3. 31 m格子(x ±約713、z −約1,116〜217)。距離に応じて高くし、中央付近は96 m以下
4. 超高層52本(|x| 105〜620)、ツインタワー2本、中央タワー(z −620、2段)
5. 約50%の建物に細い上層部を追加

形状は箱・円柱・テーパーの3種を `InstancedMesh` で描画(インスタンス属性: 寸法、seed・様式・階層)。

## 5. シェーダー・照明・空

| 対象 | 内容 |
|---|---|
| ファサード | メートル単位の窓格子4様式、`fwidth` によるAA、点灯窓、店舗階、角・冠のネオン、外装パネル。昼は白い建築・ガラス・壁面緑化。独自ヘイズ(高さ+距離) |
| 空 | 半径6,000の球。グラデーション、fBm雲(時間で流れる)、星(夜)、太陽(昼)。月・リング・恒星数は反映しない |
| 路面 | §3 |
| 広告 | ホログラム画面(加算合成、文字なし)。看板はcanvas描画の架空名称14種 |
| 照明 | 建物・空・路面はシェーダー内で完結。小物用に DirectionalLight 1 + HemisphereLight 1。影なし |
| 後処理 | MSAA 4 の HalfFloat ターゲット → UnrealBloom(夜 0.5 / しきい値0.92、昼 0.12 / 1.1)→ OutputPass。ACES、露出 夜0.95 / 昼0.8 |

小物: 屋上設備、足場板と配管、空中橋6、電線46、街灯、浮遊車6、人影34、空中交通150機、サーチライト3、航空灯。夜だけ: ネオン・看板・光芒。昼だけ: 樹木・屋上緑化・白いアーチ。静的な小物はマテリアルごとに結合。

「昼 / 夜」は利用者の切替で、時刻や惑星の自転とは無関係。

## 6. 惑星ごとの差と環境データ

地上視点に使う惑星固有値は **番号(配置シードとネオン色の選択)と `atmosphereColor`(ネオン第3色・ヘイズ)** だけ。地形種別・海・気候・重力・恒星・衛星・リング・自由浮遊は反映しない(恒星の無い `planet-043` も昼は太陽が出る)。

| データ | 内容 | 利用状況 |
|---|---|---|
| `lib/planet-system-catalog.ts` | 50件: 名称、恒星型、衛星数 `(id%3)+1`、大気色、`hasRings`(34・36)、`rogue`(43) | 全ビューの正本 |
| `planet-kit-bundle` の `planets.json` | **001〜010のみ**: category(terrestrial, ocean, desert, ice, volcanic, forest, gas_giant, ice_giant, crystal, airless_rock)、半径、配色、自転・公転、層設定 | ビルドで展開するがアプリは読まない(`lib/planet-kit` はimportされていない) |
| `planet-catalog-v50/manifest.json` | 021〜050のファイル一覧 | 環境値なし |
| `lib/planet-celestial-details.ts` | 恒星・衛星の説明文(生成値) | 惑星視点の説明パネル |

## 8. 描画性能(実測: 1フレームのWebGL描画命令。反射・後処理を含む)

| 条件 | モード | draw call | 三角形 |
|---|---|---:|---:|
| 1200×800, Stage 0 | 夜 | 388 | 約35万 |
| 1200×800, Stage 5 | 夜 | 404 | 約35万 |
| 1200×800 | 昼 | 47 | 約239〜240万 |
| 390×760, DPR 3(単体表示) | 夜 | 346 | 約35万 |

- 夜の命令数は看板(マテリアル28種)と発光スプライト(1個ずつ)が主因とみられる(コードからの推定)。昼は葉の三角形が多い。
- 建物インスタンスは `frustumCulled = false`。LODなし。CIのスモークは描画開始と昼夜切替のみ確認(待ち時間を延長済み)。

## 9. モバイル対応

| あり | なし・課題 |
|---|---|
| 幅700px未満はpixelRatio≤1.25(他は≤1.5) | 端末性能に応じた品質段階 |
| タッチのドラッグ・ピンチ、`touch-action:none` | フレームレート制限、`webglcontextlost` 対応、動きを減らす設定 |
| 縦長画面の画角・仰角補正 | **パネルが `min-h-[340px]`**。狭い画面では地上視点も約340px高になり、縦長補正が効く表示にならない見込み(コードから。実画面は未確認。§8の390×760はビュー単体) |
| | 実機での表示・速度の確認 |
| | 画面内のドラッグがページスクロールを奪う |
