# CampusSync 数学問題バンク取り込み仕様

更新日: 2026-11-21

## 目標

数学I・数学A・数学II・数学B・数学III・数学Cを横断し、重複を除いた**1,000問以上**をCampusSyncに収録する。初期の問題演習では、教科・単元・難易度・問題形式を選び、スマートフォンでも読みやすく解答できることを優先する。

## 現行課程の単元分類

- 数学I: 数と式 / 図形と計量 / 二次関数 / データの分析
- 数学A: 図形の性質 / 場合の数と確率 / 数学と人間の活動
- 数学II: いろいろな式 / 図形と方程式 / 指数関数・対数関数 / 三角関数 / 微分・積分の考え
- 数学III: 極限 / 微分法 / 積分法
- 数学B: 数列 / 統計的な推測 / 数学と社会生活
- 数学C: ベクトル / 平面上の曲線と複素数平面 / 数学的な表現の工夫

古い課程の資料は、現在の科目名・単元名へ内容ベースで再分類する。たとえば古い数学Bに置かれたベクトルは、内容を確認したうえで現在の数学Cへ割り当てる。

## 問題形式

| question_type | 解答方法 | 採点 | 知識XP |
|---|---|---|---|
| multiple_choice | 2〜6択 | サーバー自動採点 | 初回正解のみ |
| numeric | 数値入力 | サーバー自動採点・許容誤差対応 | 初回正解のみ |
| written | 証明・途中式・説明 | 模範解答との自己確認 | 対象外 |

記述問題を自動採点の対象に偽装しない。生徒の自由記述が未採点であることは画面に明示する。

## 品質・重複・公開

1. 問題文・解答・解説・出典ページ・ライセンスを一緒に保管する。
2. 取り込み時に、教科コード・単元・問題文を正規化したSHA-256を計算し、既登録問題と照合する。
3. 問題文の表記が異なる類似問題はハッシュだけでは検出できないため、公開前に人が確認する。
4. 取り込みAPIは最大100問/回。取り込んだ問題は必ず下書きにし、Adminが正答・解説・単元・ライセンスを確認してから公開する。
5. 公式解答がない問題、正答が曖昧な問題、単元が判定できない問題は公開しない。
6. 外部出典URLがある問題は、ライセンス名と帰属文を必須とする。
7. 画像が必要な問題は、図の権利を確認してから個別に取り扱う。

## 一括登録JSON

Adminの「JSONを選択して取り込む」から、1〜100件の問題配列を含むUTF-8 JSONを選択する。最上位は配列、または { "items": [...] } のどちらでもよい。

各問題の必須項目:

- subject: 表示科目名（例: 数学III）
- subject_code: math1 / matha / math2 / mathb / math3 / mathc
- unit: 現行課程の単元
- title: 問題名
- prompt: 問題本文
- question_type: multiple_choice / numeric / written
- difficulty: normal / advanced / challenge
- source_name / source_url / source_license / source_attribution

形式別項目:

- multiple_choice: options: [{ "id": "a", "text": "..." }, ...] と correct_option_id
- numeric: correct_answer と任意の answer_tolerance
- written: correct_answer（模範解答）

任意項目: explanation, source_revision, target_class。外部教材からの取り込みでは source_revision にWikibooksのrevision ID、または取得版を記録する。
