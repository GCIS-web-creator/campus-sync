# ヴェルディア地上素材ランタイムアセット

このディレクトリは `planet-006`（ヴェルディア）の地上視点専用です。

- `material-atlas.webp`: 草原・森林床・堆積岩・湖岸・透水性舗装・木質複合材・バイオフィルム屋根の7材質をまとめたPBRアトラスです。各マップは96×96pxセルで、Base Color / Normal / Roughness / AO / Height / Emissiveの6列です。
- `geography-masks-atlas.webp`: 実際の惑星マスクから切り出した地理データです。128×128pxの4領域を2×2で配置しています。
- `atlas-manifest.json`: 行・列、色空間、物理タイル寸法、地理マスクの領域と座標対応を定義します。

## 地理マスク

`geography-masks-atlas.webp` の左上はバイオーム分布（RGBA：草原・森林床・湖岸／湖底・岩地）、右上は水域（RGB：水域・深い水域・極域）、左下はタイル崩しノイズです。元素材の2048×1024マップから選んだ384×384領域を、ヴェルディア地上シーンの240×240m範囲へ対応させています。

このデータから地表の材質、水面メッシュ、森林の樹木配置、道路の水際切断を生成します。水域マスクは色補正やアルファ乗算を行わず、データとして読み込みます。タイル崩しノイズはPBRシェーダーの2方向サンプルに使い、同じ模様が規則的に繰り返される見え方を抑えます。

## PBR設定

Base Color / Emissive はsRGB、Normal / Roughness / AO / HeightはLinearとして読み込みます。NormalはOpenGL +Y upのままで緑チャンネルを反転しません。Heightは地形標高ではなく、表面の微細な凹凸にだけ使用します。物理タイル寸法は草原・森林床・湖岸3m、堆積岩6m、透水性舗装2.4m、木質複合材・屋根2mです。

元素材の大きなPC用テクスチャを全て初回ロードすると負荷が増えるため、PBR材質は軽量アトラスにまとめ、必要な7材質だけを配信します。元の巨大ZIP全体はユーザー端末へ送信しません。
