# ヴェルディア地上素材ランタイムアセット

このディレクトリは `planet-006`（ヴェルディア）の地上視点専用です。

- `material-atlas.webp`: 元のPC向けPBR素材7種を、実行時に切り出せる単一アトラスへまとめたものです。各セルは96×96pxです。
- `atlas-manifest.json`: 行・列の対応、色空間、物理タイル寸法を定義します。

地上シーンでは草原、森林床、堆積岩、湖岸、透水性舗装、木質複合材外装、バイオフィルム屋根を使用します。Base Color / Emissive はsRGB、Normal / Roughness / AO / HeightはLinearで読み込みます。Heightは表面の微細な凹凸だけに使用し、地形の標高には使用しません。

元素材の2048px解像度をそのまま格納すると初回ロード量が大きくなるため、PC素材から96px/セルのWebPアトラスを作成しました。地形の大きな起伏は専用の地形メッシュで生成し、素材のHeightマップは微細凹凸に限定しています。
