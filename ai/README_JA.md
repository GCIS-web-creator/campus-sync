# CampusSync AI

## 本番のLINE・Web回答について

本番の `/api/campus-ai` は、自由文を生成する小型言語モデルを使用しません。
質問を機能別に判定し、Supabaseに保存された実データから回答を組み立てます。

- 今日の学食：`cafeteria_daily_menus` の日本時間当日分だけを参照します。
- 学食マスター：`cafeteria_menu` の有効レコードだけを参照します。
- 混雑・行列・教室・自習室：24時間以内に更新されたデータだけを「現在」の情報として扱います。
- 落とし物：公開承認済みのレコードだけを返します。
- 実データがない、古い、または取得に失敗した場合は、その状態を明示します。別の日の献立・初期値・学習用サンプルで穴埋めしません。
- 対応項目を特定できない質問には、推測で回答しません。

## AIモデルの学習コードについて

`ai/` 以下の学習スクリプトと学習済み重みは、過去の試作・検証用です。
合成データを含むため、本番APIからは切り離されています。再学習した重みを本番に戻しても、APIの回答には反映されません。

## 主な実装

- `app/api/campus-ai/route.ts`：質問分類、Supabaseの実データ取得、回答の組み立て
- `app/api/line-webhook/route.ts`：LINEのメッセージを同じ `/api/campus-ai` に渡して返信
- `lib/school-notification-utils.ts`：既知の旧サンプル通知タイトルの除外
